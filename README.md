# Вычислительные системы реального времени (ВСРВ)

##  О проекте
Данный репозиторий содержит учебные материалы и исходный код по дисциплине **«Вычислительные системы реального времени»**.

**Учебное заведение:** РТУ МИРЭА, Институт искусственного интеллекта (ИИ), Кафедра промышленной информатики.

## 🛠 Цель курса
Освоение разработки системного программного обеспечения в среде операционной системы Linux на языке программирования C. Изучение стандарта POSIX, механизмов управления процессами, потоками и организации памяти.

## 📚 Содержание практических работ

### Практика №1-2: Знакомство со средой выполнения и ОС Linux
*   **Тема:** Основы работы в терминале Linux, структура файловой системы.
*   **Ключевые задачи:**
    *   Изучение командной оболочки Bash.
    *   Анализ дерева процессов в ОС Linux.
    *   Работа с правами доступа и пользователями.

### Практика №3: Знакомство с языком си
*   **Тема:** Написание первой программы на си и компиляция
*   **Ключевые задачи:**
    *   Ввод/вывод текста
    *   Компиляция и запуск программы


### Практика №4: Стандарт POSIX и управление процессами
*   **Тема:** Создание и управление процессами с использованием API POSIX.
*   **Ключевые задачи:**
    *   Изучение системных вызовов: `fork()`, `getpid()`, `getppid()`, `sleep()`, `exec()` семейство.
    *   Написание программ для создания дочерних процессов.
    *   Построение блок-схем алгоритмов взаимодействия процессов.

### Практика №5: Организация памяти и работа с указателями
*   **Тема:** Динамическое выделение памяти и работа с указателями в C.
*   **Ключевые задачи:**
    *   Различия между стеком и кучей (Stack vs Heap).
    *   Использование функций `malloc`, `calloc`, `realloc`, `free`.
    *   Анализ адресации одномерных и двумерных массивов.
    *   Предотвращение утечек памяти (Memory Leaks) и работа с Valgrind.

### Практика №7: Организация взаимодействия процессов. Сигналы

*   **Тема:** Межпроцессное взаимодействие (IPC) с использованием сигналов в POSIX.
*   **Ключевые задачи:**
    *   Изучение системных вызовов: `signal()`, `sigaction()`, `kill()`, `raise()`, `alarm()`, `pause()`.
    *   Обработка асинхронных событий (SIGINT, SIGFPE, SIGALRM).
    *   Управление дочерними процессами через сигналы (SIGSTOP, SIGCONT).
    *   Реализация собственных функций ожидания (custom sleep).
